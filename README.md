Sou desenvolvedor **júnior em Java**, atualmente me aprofundando em **Spring Boot** no backend e aprendendo **React + TypeScript e .NET** no frontend.

- 🔭 Atualmente desenvolvendo um site para minha igreja **IBVNova**, um sistema de gestão (tesouraria, reembolsos, gestão de pequenos grupos, controle de pessoas e membros).
